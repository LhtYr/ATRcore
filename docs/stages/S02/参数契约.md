# S02 参数与边界契约

本阶段只加载配置并检查边界输入，不积分、不运行 ELM/涡轮/轴系。
单位不作隐式换算。五项输入均为 double，W23 仅为文档别名，不是可加载键。

| 键 | 单位 | 缺省值 / 规则 |
| --- | --- | --- |
| input.p_chamber | Pa | 101325；燃烧室压力，有限且 >0 |
| input.W_ox | kg/s | 0.0001；请求 LOX 流量 |
| input.Wg | kg/s | 0.0004；请求燃料流量 |
| input.p_out | Pa | 100000；有限且 >0 |
| input.T_load | N·m | 0；正值为吸收轴能的阻力矩，负值保留 |
| initial.theta_mech | rad | 0 |
| initial.omega_mech | rad/s | 0 |
| initial.p_plenum | Pa | 400000；有限且 >0 |
| initial.p_downstream | Pa | 400000；有限且 >0 |
| shaft.J_sum | kg·m² | 0.000774；>0，参考软件回归值，可覆盖 |
| shaft.b_sum | N·m·s/rad | 0.0048；>=0，参考软件回归值，可覆盖 |
| boundary.ramp_enabled | 无量纲整数 | 0 常值 / 1 延迟斜坡 |
| boundary.delay_s | s | >=0；斜坡启用时须显式提供 |
| boundary.duration_s | s | >=0；0 表示在延迟时刻阶跃 |
| boundary.start.p_chamber | Pa | 斜坡起点，>0 |
| boundary.start.W_ox | kg/s | 斜坡请求 LOX 起点 |
| boundary.start.Wg | kg/s | 斜坡请求燃料起点 |
| boundary.start.p_out | Pa | 斜坡起点，>0 |
| boundary.start.T_load | N·m | 斜坡负载起点 |

以上是 S02 全部 19 个绑定键。ELM 系数与保护、涡轮标定参数及模块开关在各自阶段接入；本步不新增这些参数的实现。请求流量允许有限的零值、负值和归一化区间外值，原样保存；S05 才计算 effective 流量和外推标志。正腔压即使低于 p_floor 也原样保存，后续涡轮保护仍按蓝本执行。

文件使用 ASCII 或无 BOM 的 UTF-8，`key=value` 每行一项；允许空白行、行首/行尾 `#` 注释、LF/CRLF 和无末尾换行。单行上限 1023 字节（不含 LF，含 CR）；超过此长度明确拒绝。未知键、重复键、空值、尾随非数值字符、NaN/Inf、strtod 上下溢、NUL 字节和读取失败均报错。旧 p23_total/T23_total、电机/泵/控制/逆变器键不支持。

工程加载策略：显式文件必须完整给出五项 `input.*`，缺项拒绝；可选项从传入配置继承。main 则每次从缺省配置开始。启用斜坡时须完整给出两项时间和五项 start，不能依赖未声明起点。文件在自身完整性和合法性通过后才接受 CLI 覆盖，CLI 不能掩盖错误文件。加载失败时原配置逐字节不变。错误行号 1 起计；整体语义/缺项/CLI 错误行号为 0。这些是 S02 明确的文件格式策略，不是原参考程序已有行为。

CLI：`--config FILE` 至多一次；`--set key=value` 可重复；`--sample SECONDS` 至多一次，有限且 >=0。优先级为缺省 < 文件 < CLI；`--config` 在命令行中的前后位置不影响优先级，重复 CLI 键以后者为准。仅用 CLI 启用斜坡也必须给全七项斜坡参数。

常值剖面在任意合法时间返回 `input.*`。延迟斜坡使用统一 delay/duration，五个通道有各自起点，终点均来自 `input.*`：

- t < delay：两路请求流量为 0，压力和负载保持 start。这沿用参考延迟供气语义，不代表燃发器熄火或有效 W4 为 0。
- delay <= t < delay+duration：各通道从 start 线性变化到 target，支持升坡和降坡。
- t >= delay+duration：保持 target；duration=0 时在 delay 直接取 target。

`BoundaryProfile` 借用调用者上下文，须保持其存活；采样期间不能并发改写。通过 `boundary_profile_sample` 在整步起点取一次值，`BoundarySnapshot` 按值保存五项输入和采样时间，供 k1/k2/k3/k4/终态读取。采样失败不改写输出。S02 只验证此接口消费规则；实际求解器接入在 S08 验证，不宣称已完成 RK4 联调。

示例 `constant.cfg` 复现截图初始化输入，`in_range.cfg` 给出归一化区间内的数学样本，均不宣称物理稳态。`delayed_ramp.cfg` 是五通道合成时程样本，1 s 起坡、2 s 坡长，压力/负载起终点用于软件校验。
