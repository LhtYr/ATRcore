## 独立验证方法与验收口径

系数有两条数据路径：生产只读 `.inc`，工具读取单独的 ASCII CSV。二者都来自唯一冻结附录 A，但检查代码不包含生产系数表，也不以被测 evaluate 充当参考。正式脚本从蓝本重新解析 50 行，逐字核对两份文件（不自动重生成），保留图片行号映射；C 再逐一核对 **250/250** 个数值、符号、顺序和列序。故意将测试副本 beta[0] 增加 1e-8，工具正确返回 1。

独立参考以 long double 十进制尺度、独立循环和 expl 稳定分支计算归一化、50 个 z/H、升序和及温度；不调用生产 sigmoid 或 Gas。另用工具专用 C_exp 算法逐节点及温度复算。C_exp 的算术转录与原 C_Base.c 函数每次做文本核对，参考源码不改、仅链接 char。

同数学路径沿冻结公式 `abs(error)<=atol+1e-9*abs(reference)`：归一化、z/H、和取 atol=1e-12，温度=1e-7 K；有效流量尺度化误差 <=1e-10。原 C_exp 完整复算路径差异单列，含独立归一化/z 舍入差异，不将它误称为纯指数函数误差。区间内 H 绝对限值 4e-15；温度限值根据 S04 指数差异预算传播：

`sum(abs(beta))=624.85535041000003`

`T_atol=202.9*sum(abs(beta))*4e-15+1e-9=1.5071326023927561e-9 K`。

额外 1e-9 K 为归一化和升序累加舍入余量。区间外 C_exp 的软压缩差异仅报告，不强迫生产算法复刻。照片工程二进制逐位一致不是验收目标。

检查覆盖：中点、8 角点、5×5×5 网格、两下限 nextafter 下方/等号/上方的 9 种组合、零/负请求、单路为零、原初始化、压力及流量外推、燃料大于 10、同配比不同绝对流量；共 **154 个样本、7700 个节点**。另检查 NaN/Inf/非正压力、每个标量参数、无效系数引用、零尺度、计算溢出、纯评估、重复评估和成功/失败 apply。

案例与节点 CSV 均由 C 重新读取，核对实际/独立参考 z/H、逐项加权和累计、最终温度。实数输出显式转 double 后用 %.17g，内部参考仍用 long double。Python 仅作图，不判定数值 PASS/FAIL。
